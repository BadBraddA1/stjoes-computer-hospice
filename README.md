# ST Joe's Computer Hospice

Joke / meme site for **[stjoeshospice.com](https://stjoeshospice.com)** — comfort care for dying machines.

## Local

```bash
pnpm install
pnpm dev
```

## Deploy

Vercel project linked to this repo. Point DNS:

- `stjoeshospice.com` → Vercel
- `www.stjoeshospice.com` → Vercel (optional redirect)

In Vercel → Project → Settings → Domains → add `stjoeshospice.com`.

## What’s here

One-page hospice parody: patient board, visiting hours, admit CTA. Not a real hospital. Don’t send your grandma’s PC… unless that’s the joke.
